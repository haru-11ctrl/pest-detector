# Pest Detector
## 🚀 Overview

An intelligent pest detection system using Raspberry Pi, Pi Camera, and machine learning to automatically detect and classify animals in outdoor environments.

## 🧠 Features

* Real-time animal detection
* Automatic image capture
* Machine learning-based classification
* Works in outdoor environments

## 🛠️ Tech Stack

* Python
* Raspberry Pi
* Pi Camera
* TensorFlow Lite / Machine Learning

## 📂 Project Structure

* `detection/` → Core detection logic
* `images/` → Dataset and outputs
* `notebooks/` → Experiments and testing

## ▶️ How to Run

1. Download or clone the repository
2. Install required dependencies
3. Run the main Python file
